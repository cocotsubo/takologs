TakoLogs v21.3 — version FTP
============================

1. Décompressez cette archive (un dossier « takologs » avec index.html à l’intérieur).
2. Ouvrez le dossier décompressé.
3. Envoyez TOUT son contenu (index.html, assets/, .htaccess, favicon, *.php, etc.)
   dans le dossier de votre site (souvent public_html ou www).
   Écrasez les anciens fichiers. N’envoyez pas le .zip tout seul.
4. Dans Cloudflare (si tu l’utilises) : mise en cache → tout purger.
5. Sur le téléphone : ouvre takohelp.com en navigation privée, ou efface
   les données du site, puis recharge.

Le journal est enregistré dans le navigateur.
Mails : mail-send.php + Resend. PsychonautWiki : pw-api.php. TakoAI : ai-send.php.
Admin : /admin (admin-api.php).
