# TakoLogs

Journal privé de réduction des risques. Production **v28**.

- Site : argile / sable, glass, journal **local** (navigateur)
- Canal laboratoire : [`/beta`](https://takolabs.com/beta) — TakoLabs, autre design
- Instagram / X : [@TakoLogs](https://instagram.com/takologs)
- Code : [cocotsubo/takologs](https://github.com/cocotsubo/takologs)

## Produit

TakoLogs n’est pas un mode d’emploi de synthèse. C’est un journal, un catalogue (375 fiches), un comparateur, des calculateurs, un blog RdR. Rien n’est envoyé sur un serveur par défaut.

## Pages

Accueil, Sessions, Notes, Profil, Substances, Comparateur, Dommages, Réduction des risques, Neurotransmetteurs, Histoire, Blog, TakoAI, Alcoolémie, Pureté, Téléchargements, Compte, Mises à jour, TakoLabs `/beta`.

## Technique

TanStack Start, React 19, Tailwind v4, Zustand (`takologs-v1`). Export JSON côté client. Films d’aperçu dans `public/films/`.

## Avertissement

Les scores de dommages sont **relatifs et indicatifs**. En urgence : **15 / 112**. Naloxone pour les opioïdes. Un kit réactif n’est pas un laboratoire.
