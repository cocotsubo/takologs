TakoLogs v20.6 — version FTP
============================

1. Décompressez cette archive.
2. Ouvrez le dossier takologs.
3. Envoyez TOUT son contenu (index.html, assets, favicon, etc.)
   dans le dossier de votre site (souvent public_html ou www).
4. Ouvrez votre nom de domaine dans le navigateur.

Le journal est enregistré dans le navigateur (pas de compte en ligne).
Les pages substances, comparateur, effets, logs et profil fonctionnent
sans serveur Node.

Si le site est dans un sous-dossier (ex. votresite.fr/takologs/),
envoyez ces fichiers dans ce sous-dossier.
